# Body model attribution

`body-neutral.glb` is derived from the rest mesh of the **Anny** parametric body model
(Naver Corporation, Apache License 2.0, https://github.com/naver/anny), obtained from the
`anny-js` npm package (Apache-2.0). Anny is built on MakeHuman / MPFB2 assets (CC0).
The mesh was re-oriented, scaled and given per-vertex body-region tags by `tools/make_body_glb.py`.
