Liquid glass · 6 versions

What makes glass "liquid"

Frosted glass only blurs what is behind it. Liquid glass also bends what is behind it, mostly near the edges, and catches light on a thin bright rim. Drag the pill and the card around each stage and watch the squares behind them. The same background as the app is used.

Which of these can run on an iPhone? Versions 1, 2, 4, 5 and 6 work in every browser. Version 3 uses a browser feature only Chrome and Edge have, so Safari on iPhone cannot show it. Version 4 is how I would get the real bending on every phone: it draws the bent background itself.
My pick Version 4 (Lens) gives the true edge bending on iPhone and Android, with the light rim from version 2 on top. If you prefer a calmer, simpler look, version 2 is the nicest without any bending. Tell me a number and where to use it (every panel, or just the nav pill and the body panel).
